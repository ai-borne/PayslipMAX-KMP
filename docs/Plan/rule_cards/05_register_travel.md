# Rule register - travel domain (canonical topics)

SSOT index for travel rules: **one row per canonical rule topic**. A topic bundles the TR 2014 rule(s) that define it and lists every FAQ and TA-handbook paragraph that restates or applies it. Cards are written per topic (several situations each), never per source paragraph. Machine-readable twin: [register.json](register.json).

`TR rules` are the primary-authority anchors. `Order topics` (ORD) have no TR 2014 rule because they come from later MoD/DoPT/Army letters; their real authority must be found from the leads in the last column (extracted from FAQ/handbook text, **unverified**).
`FAQ` / `TA` = counts of website-FAQ entries and TA-handbook paragraphs attached to the topic (ids in register.json). Topics showing 0/0 are TR-backed only.

Topics: 67 (51 TR-anchored, 16 order-based).
